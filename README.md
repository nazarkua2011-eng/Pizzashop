# Pizzashop

A small front-end demo for a pizza ordering page.

## Description

This is a simple static project demonstrating a pizza shop UI built with HTML, CSS, and JavaScript.

## Requirements

- Modern web browser (Chrome, Edge, Firefox, Safari)

## Usage

1. Open [index.html](index.html) in your browser.
2. Interact with the UI; JavaScript behavior is in [js.js](js.js) and styles in [style.css](style.css).

## Project Files

- [index.html](index.html) — main HTML page
- [js.js](js.js) — JavaScript logic
- [style.css](style.css) — CSS styles

## Development

- Edit the files and refresh the browser to see changes.
